# Java Interview RAG

Java 面试知识库与智能训练平台，计划基于 Java 17、Spring Boot 3、Spring AI 和向量数据库，逐步实现知识文档管理、RAG 检索与评估、文本模拟面试和轻量 Agent 能力。

当前仓库处于阶段 0：项目治理与最小骨架准备。业务代码尚未初始化，后续由定时开发任务依据项目文档逐步推进。

## 项目主线

```text
Markdown 知识库
→ 文档解析与切分
→ 向量生命周期
→ RAG 问答与来源引用
→ 召回日志与 RAG 评估
→ 文本模拟面试
→ 动态追问与结构化评分
→ 错题和复习计划
→ Tool Calling
→ 必要时扩展 MCP
```

## 项目边界

- 本项目是独立的新项目，不修改 `D:\IdeaProjects\blog\blog-springboot`。
- Java 是主后端技术路线。
- 第一阶段优先完成 RAG 核心闭环和评估，不提前建设复杂 Agent 平台。
- 外部参考项目只用于设计借鉴，是否采用由真实需求和评估结果决定。
