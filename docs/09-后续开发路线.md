# 后续开发路线

> 更新时间：2026-08-13。用于约束自主开发选题，不记录开发流水账。

## 执行原则

- 每轮只完成一个可验证闭环，功能价值优先，治理能力随真实功能一起建设。
- 先建立固定评估基线，再增加检索、Agent 或图工作流复杂度；没有收益就保留结论并停止扩张。
- Java/Spring AI 继续作为主业务与 Agent 开发平台，DashScope 提供模型，MySQL/Qdrant 保存业务事实与知识资料。
- 开源项目用于参考角色闭环、状态、评估和安全边界，不复制 Python 技术栈或通用 Agent 平台。
- 简历和 JD 默认不持久化，不把模型推断包装成用户事实，不从模型自然语言直接生成写操作。

## 主开发顺序

| 优先级 | 开发闭环 | 验收重点 |
| --- | --- | --- |
| P0 | 真实文本层 PDF 补证据 | 经授权脱敏样本覆盖不同字体、嵌套表格和不规则侧栏；稳定复现缺口后才改算法 |
| P0 | RAG 困难评估集 | 20 至 30 条精确术语、相似章节、歧义、无答案和跨章节样本；输出 Hit@1、Recall@5、MRR 和拒答结果 |
| P1 | 检索增强对照 | 每次只比较一种方案；质量收益必须覆盖新增延迟、费用和维护成本 |
| P1 | 主题学习与连续路径 | 基于持久化题目、attempt 和标题路径展示学习事实；所有模型调用由用户显式触发 |
| P2 | 部署与演示收尾 | 新环境可按文档完成导入、问答、面试、复习和助手演示 |

## 特色方向：简历求职角色 Agent

这是一条主顺序之外的特色路线。它复用现有简历/JD 解析、候选人画像、证据化评分和受控 Tool Calling，不建设自由协作的多 Agent 平台。

角色按顺序推进：

1. **简历证据审计官**：提取可验真的简历事实，识别缺失、矛盾和空泛描述。
2. **岗位匹配顾问**：将已验真事实与用户提供的 JD 对齐，不把“未写”判断为“不会”。
3. **项目深挖面试官**：围绕真实项目生成基础、取舍和故障追问，可只读检索知识库。
4. **简历表达教练**：在事实不变的前提下提供候选改写，不覆盖、保存或投递简历。

首个闭环只实现“简历证据审计官”：复用现有 `resumeText` 输入，输出事实、逐字证据、信息缺失、风险和建议；Java 服务端校验所有模型引文。固定样本覆盖完整简历、缺少量化结果、时间冲突、技能堆砌、项目空泛和提示注入。日志只记录角色/Prompt/模型版本、token、耗时、状态和失败类型，不记录简历或建议正文。

## 图工作流落地路线

LangGraph 类技术不会永远停留在学习样例，但也不因“先进”而提前进入主链路。图运行时不直接提高模型能力，它主要解决状态、条件分支、有界循环、中断恢复和人工确认。

分三步落地：

1. **普通 Spring AI 基线**：先完成单次结构化审计与服务端证据验真，证明功能价值和基础质量。
2. **正式图工作流**：当流程真实出现证据失败修正、条件分支、人工确认暂停或 checkpoint 恢复时，引入图状态和节点级日志。
3. **角色扩展**：审计稳定后，将岗位匹配、项目深挖和表达建议作为专业节点或子图，不让多个角色自由对话。

候选流程：

```text
提取简历事实 -> 校验证据 -> 无效证据时最多修正一次
               -> 诊断问题 -> 可选岗位匹配 -> 生成建议
               -> 暂停等待用户确认 -> 从 checkpoint 恢复
```

Java 主项目优先比较与当前 Spring AI 版本兼容的图方案；Python LangGraph 可用于对照学习，只有在 checkpoint、HITL 或图执行能力上存在明确收益时才作为受控独立服务。无论使用哪种图框架，Java 仍负责权限、业务事实、最终写入和审计。

图方案必须与普通 Spring AI 基线使用同一批样本比较：事实准确率、证据合法率、问题识别率、虚构率、修正成功率、流程完成率、中断恢复率、平均模型调用次数、token、费用和 P95 延迟。质量或恢复能力没有明确提升，或成本明显失控时，回退到简单工作流。

## 暂缓方向

- **OCR**：当前不开发；无文本页提示改用带文本层文件或手动粘贴，除非用户重新明确提出。
- **DOCX**：有真实需求后单独评估本地解析，不与 OCR 绑定。
- **MCP、GraphRAG、跨会话用户体系**：分别等待外部客户端复用、多跳评估失败和正式数据归属需求。
- **多 Agent/A2A、通用 Agent Runtime、AI Gateway、提醒调度器**：当前不建设；第二个角色出现相同治理模式后，才提炼最小公共组件。
