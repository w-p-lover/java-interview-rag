# 需求边界

## 当前必须实现

- Java 17 与 Spring Boot 3 的最小可运行骨架。
- Markdown 文档导入、元数据和版本识别。
- 按标题、段落和最大长度进行文本切分。
- Embedding 与向量新增、更新、删除和重建。
- RAG 问答、来源引用和无可靠来源兜底。
- 召回日志、相似度、耗时和 Prompt 版本记录。
- 固定 RAG 评估问题集及批量评估结果。
- 根据目标岗位、简历和可选岗位描述生成可确认的面试准备画像，并与内部固定 RAG 评估集隔离。

## 后续阶段实现

- 混合检索、必要的 rerank 和查询改写。
- 文本模拟面试和多轮追问。
- 结构化答案评分、优点、遗漏和改进建议。
- 错题沉淀和复习计划。
- Tool Calling 和执行记录。
- 真实需求出现后的 MCP 接入。

## 当前明确不实现

- 纯 Python 主后端。
- 模型训练、微调和 LLM Infra。
- Dify、Coze、n8n 替代核心功能。
- 多 Agent 平台和通用 Agent Runtime。
- 语音、视频、防作弊、组织管理和多租户招聘平台。
- 白板、实时代码编辑器和大型后台管理系统。
- 没有当前需求支撑的微服务及中间件堆叠。

## 变更规则

用户最新明确需求可以调整本文件。自动开发可以细化实现顺序，但不得自行改变长期定位或把“后续阶段”整体提前到当前阶段。
