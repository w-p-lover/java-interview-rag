# 项目定位

## 目标

建设一个面向 Java 求职学习者的知识库与智能训练平台，通过真实工程链路证明 Java 后端、RAG 质量治理和后续轻量 Agent 能力。

## 与主项目的区别

| 项目 | 主要职责 | 重点能力 |
| --- | --- | --- |
| `blog-springboot` | 内容平台与 AI 增强知识检索 | Java 业务系统、缓存、MQ、AI 任务治理和业务接入 |
| `java-interview-rag` | 面试知识库与智能训练 | 文档切分、向量生命周期、检索质量、RAG 评估、面试追问和评分 |

两个项目保持独立。新项目可以只读参考主项目，不修改主项目，也不复制整套业务模块。

## 技术标签

```text
Java 17
Spring Boot 3
Spring AI
RAG
向量数据库
来源引用
召回日志
RAG 评估
Tool Calling
轻量 Agent
```

## 长期结果

最终形成一个能够导入 Java 面试资料、基于知识来源回答问题、评估检索质量、开展文本模拟面试、动态追问、生成结构化反馈并沉淀复习任务的独立项目。
