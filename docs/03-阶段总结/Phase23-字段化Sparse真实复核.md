# Phase23：字段化 Sparse 真实复核

> 更新时间：2026-09-02。本阶段在字段化 BM25 和高级评估指标完成后，执行一次真实 storage 三策略对照，确认真实效果边界。

## 阶段目标

在不调用 Chat、不重复追分的前提下，验证字段权重对 Dense、Sparse、Hybrid 真实固定题集的来源、排序、拒答、噪声和延迟影响。

## 运行约束

- 固定 20 题、8 份语料、18 个 Chunk。
- 最多 40 次 Embedding 请求，0 次 Chat；同一代码、数据集和模型版本不重复运行。
- 结果不达成全面提升时，保留字段化实现并扩充困难样本，不引入复杂 rerank。

## 判断

- 字段化 Sparse 保持来源级 Hit@1、Recall@5、MRR，与旧基线一致；标题路径召回为 `0.9565`，Hybrid nDCG@5 为 `0.9772`，属于局部收益，不足以宣称整体回答质量提升。
- Sparse P95 约 `18.81ms`，显著低于包含 Dense Embedding 的 Dense/Hybrid；该比较是当前单实例检索调用耗时，不代表生产长期 P95。
- Sparse 拒答准确率仍为 `0`。候选存在性策略避免了 BM25/余弦分数误比较，但非空低相关候选仍会被保留，风险已被真实复现。
- Chunk 级三道代表性题全部命中，Hard Negative 避免率为 `0.6667`；标注规模仍不足以外推完整 20 题。

## 修复与验证

- 真实运行前修复 nDCG 重复相关来源导致可能大于 `1` 的问题，改为按相关身份去重。
- 运行器增加 `--evaluate-hybrid` 和高级指标校验，结果文件记录字段权重、调用上限和 Chat 次数。
- JDK 21 Maven 定向测试和 Python 运行器语法检查通过；storage 健康检查、三策略 HTTP 评估和临时实例清理通过。
