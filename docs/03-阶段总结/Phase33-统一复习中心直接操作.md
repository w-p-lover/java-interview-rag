# Phase33：统一复习中心直接操作

## 功能成果

- 统一复习中心的每条待复习项现在支持直接标记完成和调整计划日期。
- 面试复习项调用现有带 `sessionId` 的面试复习接口，知识复习项调用现有知识复习接口，不合并两个后端任务模型。
- 操作成功后重新加载两类学习路径和概览统计，避免页面只修改局部状态导致日期、逾期和计数不一致。
- 操作失败只展示当前动作错误，保留已经加载的复习列表和进入训练深链。
- 用户身份/知识空间没有提前实现，继续按“公网、多设备、多人共享或真实越权风险”作为进入条件。

## 主要文件

- `frontend/src/views/ReviewCenterView.vue`：增加完成、改期动作、动作级 loading、错误提示和移动端布局。
- `docs/04-当前进度.md`、`docs/08-项目技术栈与功能总结.md`、`docs/09-后续开发路线.md`：同步统一状态判断、用户身份进入条件和本轮闭环事实。

## 验证

- `npm run build`（含 `vue-tsc --noEmit`）通过。
- `git diff --check` 通过。

## 边界

- 本轮未新增后端接口、数据库表或用户身份模型，完全复用现有完成/改期接口。
- 未在真实 storage 数据上执行浏览器联调；前端类型检查和生产构建已通过。
