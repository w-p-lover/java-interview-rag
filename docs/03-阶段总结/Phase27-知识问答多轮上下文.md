# Phase27-知识问答多轮上下文

## 升级目标

让知识问答能够处理当前页面内的有限连续追问，同时控制历史上下文大小，避免把无主语追问直接送入检索或让 Prompt 无限增长。

## 完成内容

- `RagAnswerRequest` 支持携带问答历史。
- `RagAnswerService` 最多保留最近 4 轮历史；遇到有限中文指代词时，将上一轮问题与当前追问组成检索问题。
- 历史回答按约 800 Token 的保守字符近似限制，并在 Prompt 中明确历史仅用于理解，不作为资料证据。
- 同步接口和 SSE 接口均支持历史参数；旧单参数服务方法保留兼容。
- Vue 问答页面在当前页面内保留最近 4 轮已完成可靠回答，清空问题时同时清空历史；不落库、不跨设备同步。

## 验证结果

- Java 21 下 `RagAnswerServiceTest`、`RagAnswerControllerTest` 通过，覆盖指代改写和历史预算。
- 前端 `npm run build`（含 `vue-tsc --noEmit`）通过。

## 边界与后续

当前只识别有限指代词，未实现主题切换、跨轮纠正或真实 tokenizer；预算是保守字符近似，不代表模型厂商 Token 精确计数。下一步仅在真实输入出现时再补齐统一 Prompt 预算或更完整的问题改写策略。
