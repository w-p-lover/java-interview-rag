## 当前阶段

阶段 8.1“面试配置与多来源出题”已完成，阶段 8.2“知识库题库”首版已形成可运行闭环。知识库、可信 RAG、文本面试、证据化评分、复习 attempt、统一复习中心、受控 Tool Calling、简历角色和可恢复付费评估已经形成可运行闭环。

- 正式草稿确认新增稳定 `requestId`：前端在草稿生成后创建并在重试期间复用，后端先查数据库、再依赖唯一键处理并发创建并返回胜出会话；草稿 SHA-256 缓存仍只承担短期费用优化，不再与正式幂等混淆。
- `029_interview_session_request_id.sql` 已在目标 MySQL 5.7.36 执行，`request_id` 为可空 `VARCHAR(100)`，唯一索引 `uk_interview_session_request_id` 已核对，执行时会话表为 0 行。
- 新增统一面试草稿入口：相同材料、题数、Skill、难度和运行契约在当前实例内共享一次进行中计算并复用 30 分钟，最多保留 100 份；显式重新生成才绕过复用，失败计算不占用后续重试机会，缓存不保存原始简历/JD。
