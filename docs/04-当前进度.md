## 已确认的产品边界与优化方向

- 资料库入口只面向需要长期版本登记、切分、向量化和复用的 Java 学习资料及项目技术说明。
- 简历与可选 JD 属于模拟面试输入，应在 `/interview` 独立上传并自动提取正文，默认不进入资料库、不写向量；文本粘贴降为备用方式。
