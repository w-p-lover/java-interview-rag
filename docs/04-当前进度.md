# 当前进度

阶段 2：向量生命周期，已开始业务实现。

## 已完成

- 创建独立 Git 仓库。
- 建立项目级 `AGENTS.md`。
- 建立项目定位、需求边界、技术方案和阶段路线。
- 建立进度、开发记录、参考项目调研和技术决策文档。
- 明确所有新增代码注释默认使用简体中文。
- 创建每日自主开发定时任务 `java-interview-rag`，北京时间每天 09:00 运行。
- 初始化 Java 17、Spring Boot 3.5.16 和 Maven Wrapper 3.9.14 最小骨架。
- 创建应用启动入口、应用名称配置和上下文加载测试。
- 建立不可变 Markdown 文档模型，保存来源、原始内容和内容版本。
- 使用换行符归一化后的 UTF-8 内容计算 SHA-256 版本标识。
- 建立不可变 Markdown section 模型，保存来源、顺序、标题级别、标题路径和正文。
- 实现 ATX 标题逐行解析，并避免将围栏代码块内的 `#` 误判为标题。
- 建立不可变 Markdown chunk 模型，保存来源、全局顺序、原 section 顺序、标题级别、标题路径和正文。
- 实现段落优先的最大字符长度切分，超长单段严格按上限连续切开，空正文不生成 chunk。
- 实现进程内 Markdown 导入登记，按“来源 + 内容版本”拒绝重复登记，并允许同来源的新版本和同内容的不同来源分别登记。
- 实现 UTF-8 Markdown 单文件导入，使用显式逻辑来源串联文档创建、重复判定、标题解析和 chunk 切分。
- 建立不可变导入结果，明确区分首次导入、重复导入和成功但没有 chunk 的空文档。
- 增加 Spring MVC multipart 导入接口，接收 Markdown 文件与逻辑来源，返回版本、导入状态和可追踪 chunk。
- 建立 Vue 3、Vite、TypeScript 前端子项目，按 API、路由、视图、组件和 Sass 样式分层组织。
- 将首个 Web 页面重构为“求职面试工作台”，明确“求职目标 → 资料准备 → 模拟面试 → 训练复盘”的产品主线。
- 将 Markdown 导入降为资料准备阶段的真实能力，支持简历、岗位描述和面试资料的选择、拖放、来源编辑、版本状态与 chunk 明细。
- 完成桌面与移动端响应式布局、键盘焦点和减少动效适配，并使用低装饰的中性浅色产品主题。
- 将独立项目后端开发端口固定为 `18080`，避免与本机已有的 `8080` Tomcat 冲突。
- 将导入登记器抽为稳定接口，默认 `local` profile 保留进程内实现。
- 增加 MyBatis-Plus 版本实体、Mapper 和 MySQL 登记器，通过数据库唯一键实现跨进程“来源 + 版本”重复判定。
- 增加 `storage` profile，使用 Druid、MySQL、DashScope Embedding 和独立 Qdrant collection 配置。
- 增加 Qdrant 非阻塞启动探测，向量库不可用时只记录警告。
- 提供只包含 MySQL 8 与 Qdrant 1.10.1 的 Compose、版本表初始化 SQL 和无密钥示例配置。
- `storage` profile 只读导入主项目服务器 `.env`，复用连接地址与凭据，但强制使用独立数据库和 collection。
- 已在服务器创建 `java_interview_rag` 数据库、版本表和 `java-interview-rag-chunks` collection，并完成跨进程持久化去重验证。
- 增加 Markdown chunk 索引接口；`local` profile 保持无外部向量依赖，`storage` profile 使用 Spring AI `VectorStore` 批量写入 Qdrant。
- 使用“来源 + 文档版本 + chunk 顺序”生成稳定 UUID，并保存来源、版本、顺序和标题路径元数据。
- 相同来源与版本在向量化前短路，不重复调用 Embedding 或写入 Qdrant。
- 向量写入失败时撤销 MySQL 或内存版本登记，使相同文档能够重试。
