# 当前进度

> 更新时间：2026-08-13。这里只保留当前快照；完整历史和逐轮验证见 [开发记录](05-开发记录.md)。

## 当前阶段

项目处于阶段 7“学习闭环与受控 Agent”。知识库、RAG、文本面试、证据化评分、复习 attempt 和最小 Tool Calling 均已形成可运行闭环；当前重点是扩大质量证据，并在真实简历角色中逐步引入 Agent 与图工作流能力。

## 已完成能力

### 知识库与 RAG

- Markdown 版本化导入、标题/段落切分、无正文章节树和大小写敏感来源语义。
- MySQL 版本登记与 Qdrant 向量新增、替换、重建和来源级删除，Embedding 每批最多 10 个 chunk。
- `/answer` 提供资料目录、详情、章节检索草稿、原文检索、可靠回答和完整来源核对。
- 召回日志、20 道六类困难检索题和回答要点评估；检索报告包含 Hit@1、Recall@5、MRR、完整标题路径召回和无答案拒答准确率。

### 面试与简历输入

- PDF/Markdown/TXT 简历和可选 JD 可生成候选人画像、首轮问题、动态追问、逐题评价和最终报告。
- PDFBox 逐页收集文本/图像证据并保守调整双栏；8 类确定性样本为 8/8、文本关键短语 35/35。
- 正式和复习评价的回答/知识引文均由 Java 服务端验真；`v3/v2` 两轮 8 次成功评分均通过证据校验，但分数仍有样本级波动。
- 简历和 JD 默认不进入知识库、不向量化、不在浏览器或业务表中长期保存。

### 学习闭环与 Agent

- 完成复习任务、幂等完成、计划日期、多次 attempt、单会话历史和确定性下一题推荐。
- 复习助手只暴露任务查询、进展复盘和确认改期三个工具。
- 工具具备会话作用域、参数校验、写入人工确认、执行日志；助手请求记录模型、token、耗时和失败类型，不保存正文。
- 模型 HTTP 层只对连接失败/超时、429 和 5xx 最多重试一次，不在业务层重放写工具。

### 数据与前端

- 独立 MySQL 数据库和 Qdrant collection 已用于 storage profile，当前 6 个资料来源均有可读章节目录。
- Vue 已提供资料准备、资料问答、文本面试、复习和助手入口，并保持移动端可用。
- 当前浏览器只保存最近 8 场会话 UUID；没有用户身份前不建设后端全量历史或跨设备趋势。

## 当前基线与边界

- PDF：`pdfbox-layout-aware-v2`，8/8 固定样本、35/35 文本关键短语；OCR 当前不开发。
- RAG：旧 6 题窄语料为 6/6 首位命中；当前已扩展为 20 题、8 份竞争语料，但尚未授权执行会产生 Embedding 费用的真实新基线，不能用旧结果代表当前指标。
- 评分：证据结构已验证，模型分数仍存在波动，不能声称长期稳定。
- 数据库：共享 MySQL 5.7 当前运行周期的 `max_allowed_packet` 已调为 1 MiB，仍需由运维写入服务器配置后跨重启复核。
- 本机 `storage` profile、8080 端口和前端代理属于用户环境，不作为所有环境默认值提交。

## 下一步

唯一选题入口为 [后续开发路线](09-后续开发路线.md)。RAG 困难评估代码已完成，下一步在明确接受 Embedding 费用后运行 20 题真实基线，并按失败分布决定是否需要查询改写、混合检索或 rerank；没有授权时优先推进不依赖 OCR 的简历证据审计官确定性骨架。图工作流只有在真实出现条件分支、有界修正、HITL 或 checkpoint 恢复后才进入正式主链路。
