## 已完成能力

- Markdown 版本化导入、标题/段落切分、无正文章节树和大小写敏感来源语义。
- MySQL 版本登记与 Qdrant 向量新增、替换、重建和来源级删除，Embedding 每批最多 10 个 chunk。
- `/answer` 提供资料目录、详情、章节检索草稿、原文检索、可靠回答和完整来源核对。
- 召回日志、20 道六类困难检索题和回答要点评估；检索报告包含 Hit@1、Recall@5、MRR、完整标题路径召回和无答案拒答准确率。
- 评估接口可在不改变生产检索的前提下，对照原查询与确定性子句拆分 + RRF；当前 20 题会拆分 13 题、增加 29 次查询，真实 Embedding 指标尚未运行。

### 面试与简历输入

- PDF/Markdown/TXT 简历和可选 JD 可生成候选人画像、首轮问题、动态追问、逐题评价和最终报告。
- PDFBox 逐页收集文本/图像证据并保守调整双栏；`pdfbox-layout-aware-v3` 将轻微错位的右侧日期/地点按视觉行归组，8 类确定性样本为 8/8、文本关键短语 35/35，一份授权真实单页 PDF 的学校、公司和两个项目均恢复为主体先于时间输出。
- 正式和复习评价的回答/知识引文均由 Java 服务端验真；`v3/v2` 两轮 8 次成功评分均通过证据校验，但分数仍有样本级波动。
- 简历和 JD 默认不进入知识库、不向量化、不在浏览器或业务表中长期保存。

### 学习闭环与 Agent

- 完成复习任务、幂等完成、计划日期、多次 attempt、单会话历史和确定性下一题推荐。
- 复习助手只暴露任务查询、进展复盘和确认改期三个工具。
- 工具具备会话作用域、参数校验、写入人工确认、执行日志；助手请求记录模型、token、耗时和失败类型，不保存正文。
- 模型 HTTP 层只对连接失败/超时、429 和 5xx 最多重试一次，不在业务层重放写工具。
- 简历证据审计官后端基线已区分确认事实、信息缺失、风险和建议；事实引文由 Java 逐字验真，强提示注入行在进入模型前隔离，请求日志不保存简历或审计正文。
- `resume-evidence-audit-v3` 明确项目、技术、职责和结果的语义边界，保留 30 条上限并定义多项目容量优先级；九类 `dataset-v6` 新增项目职责与 25 条多段容量样本，报告提供七种事实类型的准确率/召回率和容量诊断。
- 固定评估已升级为十一类 `dataset-v7`：新增日期前置、多段教育/任职两种全合成版式，并将长简历容量样本扩为 30 条互不重复原子事实。授权真实基线为 11/11 审计与结构成功、事实准确率 `0.9677`、事实召回率 `1.0000`、证据合法率 `1.0000`、虚构率 `0.0323`、严格通过 `9/11`。

## 当前基线与边界

- PDF：`pdfbox-layout-aware-v3`，8/8 固定样本、35/35 文本关键短语；新增轻微错位右侧元数据回归，并通过一份授权真实单页 PDF 视觉复核。OCR 当前不开发。
- RAG：20 题、8 份语料和 18 个 chunk 的真实 `text-embedding-v3` 基线为 Hit@1 `1.0000`、Recall@5 `0.9706`、MRR `1.0000`、标题路径召回 `0.9130`、无答案拒答准确率 `1.0000`；主要缺口是跨主题 Map 题漏召回普通 HashMap，以及一条扩容标题路径漏召回。
- 评分：证据结构已验证，模型分数仍存在波动，不能声称长期稳定。
- 简历审计：生产使用 `resume-evidence-audit-v3`。v7 证明当前 11 个固定样本没有事实遗漏，教育/任职扩展样本与 `30/30` 容量样本均完整命中，但 3 条类型外事实使准确率降为 `0.9677`。该结果不能外推为完整简历解析，也不能用召回满分掩盖类型误归类；页面继续只表述“已确认事实”。
- 费用保护：RAG 与简历审计 Python 运行器默认在首个 HTTP 请求前拒绝执行，必须分别显式提供 `--allow-embedding-calls` 或 `--allow-chat-calls`；直接调用后端付费接口仍需由执行者确认授权。
- 数据库：共享 MySQL 5.7 当前运行周期的 `max_allowed_packet` 已调为 1 MiB，仍需由运维写入服务器配置后跨重启复核。
- 本机 `storage` profile、8080 端口和前端代理属于用户环境，不作为所有环境默认值提交。
