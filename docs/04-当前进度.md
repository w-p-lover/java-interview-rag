# 当前进度

本轮修复真实 DaCapo JVM 基准论文暴露的双栏阅读顺序错误：约 3.9% 页宽的标准栏沟不再把左右栏正文逐行拼接，跨栏标题会分隔前后双栏区域，轻微伸入中缝的单栏行也不会让整页回退为单栏。22 页中 11 页识别出明确双栏，前 5 页全部恢复左右栏顺序，结构块从 475 个收敛为 367 个，页 1/2 的跨栏伪 `TABLE` 消失。
