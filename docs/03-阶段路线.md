# 阶段路线

本文件只保留长期阶段目标。当前执行顺序、子闭环和验收标准统一维护在 [后续开发路线](09-后续开发路线.md)。

## 阶段 0：治理与最小骨架（已完成）

建立仓库规则、Java 17/Spring Boot 3 骨架、文档职责和无密钥配置边界。

## 阶段 1：结构化知识库（已完成）

完成 Markdown、TXT 和文本型 PDF 导入，保留标题层级、页面、内容块、Chunk 顺序和内容版本。

## 阶段 2：索引生命周期（已完成）

完成 Qdrant/Lucene 索引、幂等导入、版本替换、重建、删除、历史回退、失败补偿和一致性巡检。

## 阶段 3：可信 RAG（已完成）

完成资料发现、Dense/BM25/Hybrid-RRF、可靠拒答、来源引用、claim 证据校验、SSE、缓存和降级。

## 阶段 4：RAG 评估与质量诊断（已完成首版）

完成固定题集、检索/回答分层指标、Hard Negative、PDF 结构评估、召回日志、回答反馈和人工失败诊断。后续质量问题按真实失败样本处理，不持续扩基线代替开发。

## 阶段 5：文本面试训练（已完成）

完成独立简历/JD 输入、画像、首轮问题、动态追问、证据化评分、持久化会话、事件时间线和最终报告。

## 阶段 6：复习与重复练习（已完成）

完成复习任务、计划日期、多次 attempt、同题再练、进步比较、统一复习中心和知识问答复习路径。

## 阶段 7：受控 Agent 与投递前收口（当前）

已完成受控 Tool Calling、简历证据审计、岗位匹配、表达教练、项目深挖和可恢复付费评估。当前只完成 storage 反馈回归链路、一次性角色验收、一个真实 RAG 失败、项目深挖评价收束和候选版本封板。

## 阶段 8：面试产品编排

融合面试配置、多来源出题、知识库题库、Skill/Rubric 和简历中心，使知识、简历、JD、项目事实、题目、评分和复习形成统一产品流程。

## 阶段 9：异步、索引与资源治理

完成统一任务恢复协议、attempt fencing、心跳和卡住任务恢复；增加 Dense/Sparse 临时构建与原子发布、多模型 Provider 和对象存储。

## 阶段 10：实时交互与求职流程

在复用现有会话、评分和复习领域的前提下增加语音面试；通过面试日程串联简历、JD、准备、模拟、真实问题和复盘。

## 阶段 11：评估与交付收口

统一检索、回答、评分和模型对照运行，完成产品工作台、容器部署、HTTPS/WSS、迁移、备份恢复和候选版本冻结。

## 阶段控制

- 同一时间只推进一个阶段中的一个完整用户闭环。
- 阶段内先完成主流程和关键失败恢复，再进入下一个子系统。
- 新阶段不得降低现有 RAG、证据校验、隐私、幂等和恢复能力。
- 已实现事实见 [项目技术栈与功能总结](08-项目技术栈与功能总结.md)，当前状态见 [当前进度](04-当前进度.md)，条件型问题见 [问题清单](11-问题清单.md)。
