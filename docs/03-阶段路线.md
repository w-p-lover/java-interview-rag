# 阶段路线

## 阶段 0：治理与最小骨架

目标：建立仓库规则、项目文档和可运行的 Spring Boot 最小骨架。

验收：治理文档完整，构建文件和入口存在，最小启动或上下文测试通过，配置中没有真实密钥。

## 阶段 1：Markdown 知识库

目标：完成文档元数据、版本识别、Markdown 标题解析和 chunk 切分。

验收：相同版本不重复导入，标题层级和 chunk 顺序可追踪，边界场景有针对性验证。

## 阶段 2：向量生命周期

目标：完成 Embedding、向量入库、文档更新删除和手动重建。

验收：文档与向量关联清晰，新增、重复、更新、删除和失败状态可验证。

## 阶段 3：RAG 问答闭环

目标：完成问题检索、上下文生成、模型回答、来源引用和知识不足兜底。

验收：回答能够返回真实来源，无可靠来源时不会伪造依据。

## 阶段 4：召回日志与 RAG 评估

目标：记录检索参数、召回结果和耗时，建立固定评估集并批量比较结果。

验收：能够根据数据解释检索效果，并比较切分、topK、阈值和 Prompt 变更。

## 阶段 5：RAG 质量增强

目标：根据评估结果决定是否增加混合检索、rerank 和查询改写。

验收：新增能力必须有评估数据证明收益。

## 阶段 6：文本面试训练

目标：完成面试配置、提问、动态追问、逐题结构化评分和最终报告。

验收：一次文本面试可以完整执行，反馈包含知识来源、评分依据和改进项。

## 阶段 7：学习闭环与 Agent 工程

目标：增加错题、复习计划、Tool Calling、执行记录，以及实际需要出现后的 MCP。

验收：工具调用边界清楚、结果可追踪、失败可处理，不扩张为通用 Agent 平台。

## 调整原则

阶段顺序用于控制主线，可以在阶段内部自主调整任务；RAG 闭环和评估完成前，不把主要精力转向后续 Agent 功能。
