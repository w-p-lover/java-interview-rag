# 参考项目调研

## 记录规则

每次调研记录参考模块、解决的问题、可借鉴内容、不适合内容、是否采用、Java 实现方式和许可证边界。当前任务已有清晰方案时，不为调研而调研。

## interviewstreet/hiring-agent

- 地址：https://github.com/interviewstreet/hiring-agent
- 定位：简历结构化解析、GitHub 信号补充和可解释候选人评分流水线。
- 可借鉴：多阶段处理、Prompt 模板、结构化输出、评分标准、证据说明、中间结果缓存和模型供应商抽象。
- 不适合直接采用：Python 主技术栈、招聘方筛选定位、GitHub 候选人评分和第一阶段 PDF 解析。
- 当前判断：保留为评分与评价流水线参考，等进入结构化面试评分阶段再深入研究。
- 许可证：MIT；如后续复用具体代码必须保留并遵守相应许可要求。

## 1146345502/aural-oss

- 地址：https://github.com/1146345502/aural-oss
- 定位：支持聊天、语音和视频的开源 AI 面试平台。
- 可借鉴：面试配置、动态追问、逐题评价、练习模式、最终报告和模型可插拔设计。
- 不适合当前阶段：语音视频、防作弊、团队管理、多租户、候选人邀请、白板和大型前端平台。
- 当前判断：保留为面试产品闭环参考，RAG 评估阶段完成后再判断具体采纳范围。
