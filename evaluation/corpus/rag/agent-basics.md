# Agent 与工具调用

## RAG 与 Agent 的职责

RAG 负责检索可核验的知识上下文，主要解决回答依据从哪里来；Agent 在模型判断后调用后端工具，主要解决如何执行明确动作。一次应用流程可以同时使用两者，但不能把检索到文本等同于已经完成工具执行，也不能让模型自然语言直接成为写操作参数。

## 工具治理边界

工具参数必须由服务端按业务规则校验，工具权限应限制在当前用户、会话和请求允许的资源范围内。模型生成的标识、日期或状态不能绕过既有领域校验，高风险写操作需要在执行前获得与真实参数一致的人工确认。

工具执行应记录工具名、成功状态、耗时和受控错误类型，用于排查选择错误、参数错误和外部依赖失败。日志不应默认保存简历、回答、知识正文或密钥等敏感内容。
